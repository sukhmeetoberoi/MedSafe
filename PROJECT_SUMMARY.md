## 🏗️ Technical Architecture

### Frontend Stack
- **React 18+** with functional components and hooks
- **Vite** for fast development and optimized builds
- **Tailwind CSS** with custom medical theme
- **Framer Motion** for professional animations
- **Axios** with custom interceptors
- **Custom Hooks** for API state management

### Backend Stack
- **FastAPI** for high-performance Python APIs
- **SQLAlchemy** ORM with production-ready database models
- **OCR**: Tesseract + PyMuPDF + Google Vision
- **NLP**: spaCy with medical entity patterns
- **Presidio**: HIPAA-compliant PHI detection
- **LLM**: OpenAI GPT-4 & Google Gemini integration
- **File Service**: Secure upload and storage management

### AI/ML Pipeline
1. **File Upload** → Secure validation and storage
2. **OCR Processing** → Text extraction with preprocessing
3. **PHI Redaction** → HIPAA-compliant privacy protection
4. **NLP Analysis** → Medical entity extraction
5. **AI Summarization** → Dual clinician/patient summaries
6. **Q&A System** → Interactive question answering
